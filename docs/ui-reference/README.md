# UI 参考图

## 当前主参考图

- **文件**：`niuma-home-peach-v1.png`
- **版本**：peach-blush 粉色版 v1
- **用途**：「牛马命历」首页视觉参考

## 视觉要点

- **粉色底色**：页面背景采用 warm peach blush，柔和粉调
- **珊瑚红主卡**：核心信息卡片使用珊瑚红色
- **深棕文字**：所有文字使用深棕色系，柔和但有分量
- **暖白卡片**：普通卡片使用暖白底色
- **新中式命历感**：有传统命历的仪式感但不能俗气
- **牛马幽默气质**：面向当代年轻人，文字语气轻松诙谐
- **移动端 App 层级**：页面交互、间距、圆角、阴影均符合移动端 H5 习惯

## 参考原则

1. **不要求像素级复刻**，但必须继承整体视觉方向
2. **禁止改回米黄色背景**
3. **禁止使用大面积亮黄色**
4. **禁止做成传统网页黄历表格**
5. **禁止做成普通 AI 聊天框**
